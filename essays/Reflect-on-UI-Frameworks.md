# Is Bootstrap Really Worth the Trouble?

### My Experience Learning UI Frameworks with Bootstrap 5

---

When I first started learning HTML and CSS, I thought building a website was pretty straightforward. You write the HTML to organize everything, use CSS to make it look nice, and keep adjusting things until the website looks how you want it to.

Then I started learning Bootstrap 5 in ICS 314.

At first, I did not really understand why we needed another framework when we were already learning how to build websites using HTML and CSS. It seemed like we were making things more complicated by introducing a bunch of new classes and rules that we had to remember.

However, after working on several assignments using Bootstrap 5, I started to understand why developers use UI frameworks. Although they can be frustrating to learn, they can also make building websites a lot easier once you understand how they work.

---

## Learning Bootstrap 5

One of the first things I noticed about Bootstrap was how different it felt compared to writing regular CSS.

Instead of creating my own CSS classes for every element, I could use Bootstrap's existing classes to control the layout, spacing, colors, and other parts of the website.

For example, if I wanted to add spacing around an element, I could use a class like `p-3` instead of writing a separate CSS rule. Bootstrap also provides components like navigation bars, buttons, dropdown menus, and cards.

At first, remembering all these classes was confusing. Sometimes I would change a class expecting one result, but the website would look completely different from what I wanted.

I also had to learn how Bootstrap's grid system works. Classes like `container`, `row`, and `col` were unfamiliar to me, and it took some experimenting to understand how they affected the layout.

What helped me was actually building websites rather than just reading about the framework.

---

## Recreating Websites with Bootstrap

In ICS 314, I worked on several assignments where I had to recreate existing websites using Bootstrap 5.

Some examples were Island Snow, Murphy's Bar and Grill, Banyans Craft Kitchen + Lounge, and Craigslist.

These assignments helped me understand how useful Bootstrap can be when building a website with multiple sections.

For example, when I was working on the Murphy's and Banyans websites, I had to create navigation bars that looked similar to the original websites. I also had to make sure the navigation worked properly when the browser window became smaller.

Bootstrap made this easier because it already has a responsive navbar component that can collapse into a menu on smaller screens.

However, that did not mean everything worked perfectly the first time.

I remember having problems with the navbar colors, hover effects, background images, and spacing. Sometimes a navigation link would stay highlighted when it was not supposed to, or an image would not display at the correct size.

I had to go back through the code and figure out whether the problem was coming from Bootstrap or from my own CSS.

Even though that was frustrating, I think it helped me understand that using a framework does not automatically make someone good at web development. You still need to understand the underlying HTML and CSS to customize things and fix problems.

---

## Why Not Just Use HTML and CSS?

One question I had while learning Bootstrap was why I should use a framework instead of just writing everything myself.

I think the biggest advantage of using Bootstrap is that **it saves time and makes websites easier to keep consistent**.

Without Bootstrap, I would have to write more of my own CSS for things like navigation bars, responsive columns, buttons, and spacing.

If I were building a larger website, that could become a lot of repeated code.

With Bootstrap, many of these features are already available. Instead of building every component from scratch, I can focus more on the actual content and appearance of the website.

Another advantage is responsive design.

People visit websites using phones, tablets, laptops, and desktops. Making sure a website looks good on all those different screen sizes can be difficult.

Bootstrap provides responsive breakpoints and layout classes that help developers adjust how their websites appear on different devices.

I noticed this when working on my navbar assignments. I could have a full navigation bar on a desktop screen and a collapsed menu on a smaller screen without having to build the entire responsive behavior myself.

That made me realize how much extra work frameworks can save.

---

## The Software Engineering Benefits

I think UI frameworks become even more useful when multiple developers are working on the same project.

If everyone writes their own CSS differently, the website could end up looking inconsistent. One person might use different spacing, button styles, or layout methods from another person.

Using a framework like Bootstrap gives developers a common set of classes and components to work with.

This can make the code easier to understand and maintain because developers are following a shared system instead of inventing a different approach for every part of the website.

It can also help when someone new joins a project. If they already understand Bootstrap, they can recognize many of the classes and components without needing to learn an entirely custom styling system.

However, I do not think Bootstrap is always the best choice.

If someone is making a very small website with only a few elements, using regular HTML and CSS might be simpler. Bootstrap can also make websites look similar if developers only use the default styles without customizing them.

There is also a learning curve, which I definitely experienced during these assignments.

To me, the decision depends on the project. A framework is useful when its existing features save more time than it takes to learn and customize them.

---

## What I Learned

Before learning Bootstrap 5, I thought UI frameworks were just another complicated thing that programmers had to learn.

Now I see them differently.

After recreating different websites in ICS 314, I realized that Bootstrap is not supposed to replace HTML and CSS. It is supposed to make common web development tasks easier.

I still had to understand how websites were structured, how CSS worked, and how to troubleshoot problems when something did not look right.

The biggest thing I learned is that **the time spent learning a framework can save a lot more time in the future**.

Although I found Bootstrap confusing in the beginning, I became more comfortable with it as I continued working on different assignments.

I think this experience also changed how I look at learning new programming tools. Something that feels unnecessary or complicated at first might actually become useful once I understand its purpose.

Overall, I think Bootstrap 5 is worth learning, especially for developers who want to build responsive websites efficiently.

I would still want to improve my regular CSS skills because I do not want to depend entirely on a framework. However, I can definitely see myself using Bootstrap or another UI framework in future web development projects.
