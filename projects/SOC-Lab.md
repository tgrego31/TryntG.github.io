My Home Security Operations Center Lab is a cybersecurity project that I built to gain practical experience with tools and techniques used by security analysts.

The goal of this project was to create my own controlled environment where I could generate, monitor, and investigate security activity without affecting real production systems.

I created a virtual environment where I could observe system and network activity, review security logs, and investigate events that could potentially represent suspicious behavior.

Through this project, I gained hands-on experience with cybersecurity concepts such as security monitoring, SIEM, log analysis, network security, threat detection, virtualization, and basic incident investigation.

One of the main reasons I wanted to build my own SOC lab was to move beyond only reading about cybersecurity. Instead of just learning what security alerts and suspicious activity might look like, I was able to see activity occurring inside my own environment and investigate what happened.

Building this lab helped me better understand how different parts of cybersecurity work together, including networking, operating systems, logging, monitoring, and incident response.

This project also increased my interest in cybersecurity and SOC-related work because it allowed me to practice analyzing systems from a defensive security perspective.
